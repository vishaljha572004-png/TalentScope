Practice smarter. Perform better. Get hired faster.


📌 About
Talent-Scope is a full-stack AI-powered interview preparation platform that simulates real interview experiences through intelligent question generation, voice-based responses, real-time AI evaluation, and detailed performance analytics.
Built for job seekers who want structured, personalized, and affordable interview practice — without needing a human interviewer.

✨ Features

🤖 AI Smart Interview — Role-specific questions generated by OpenRouter AI (GPT-4o-mini)
🎙️ Voice Interview — Speak your answers using Web Speech API with live transcription
👩 Animated AI Avatar — Canvas-based interviewer avatar with lip-sync animation
📊 Performance Analytics — Scoring across Confidence, Communication & Correctness
📄 Resume-Based Interview — Upload PDF resume for personalized questions
🔍 ATS Resume Checker — Analyze resume against job descriptions with keyword matching
📝 Interview Modes — Technical & HR interview rounds
💳 Credits System — Razorpay payment integration for premium access
📈 Interview History — Track all past sessions with scores and AI feedback
📑 PDF Reports — Download detailed performance reports

🚀 Getting Started
Prerequisites

Node.js v18+
MongoDB
Firebase project
OpenRouter API key
Razorpay account

Installation
bash# Clone the repo
git clone https://github.com/yourusername/talent-scope.git
cd talent-scope

# Install server dependencies
cd server
npm install

# Install client dependencies
cd ../client
npm install
Environment Variables
server/.env
envPORT=8000
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret
OPENROUTER_API_KEY=your_openrouter_key
RAZORPAY_KEY_ID=your_razorpay_key_id
RAZORPAY_KEY_SECRET=your_razorpay_secret
client/.env
envVITE_FIREBASE_APIKEY=your_firebase_api_key
VITE_RAZORPAY_KEY_ID=your_razorpay_key_id
Run the App
bash# Start server
cd server
npm run dev

# Start client (new terminal)
cd client
npm run dev
Open http://localhost:5173 in Google Chrome for full voice support.

🔑 Key API Endpoints
POST /api/auth/google          → Google authentication
GET  /api/user/current-user    → Get logged-in user
POST /api/interview/resume     → Parse resume PDF
POST /api/interview/generate-questions → AI question generation
POST /api/interview/submit-answer     → Evaluate answer
POST /api/interview/finish            → Generate report
GET  /api/interview/get-interview     → Interview history
POST /api/ats/analyze                 → ATS resume check
POST /api/payment/order               → Create Razorpay order
POST /api/payment/verify              → Verify payment

⚠️ Important Note

Voice features require Google Chrome browser. Brave, Firefox, and other browsers may block Google Speech Recognition API.
